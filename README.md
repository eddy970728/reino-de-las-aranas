# Spider Kingdom: Awakening

RPG táctico por turnos de **LunaDog Games**, la división de videojuegos de **LunaDoggyBru Studios**. Creado por Eddy Rodes.

- `index.html`: el juego completo en un solo archivo.
- `.github/workflows/build-apk.yml`: en cada cambio prueba el juego y compila `spider-kingdom.apk` (para probar en el móvil) y `spider-kingdom.aab` (para Google Play). Salen en *Releases*.
- `pruebas/`: pruebas automáticas (humo, capítulos, campaña, guardado, interfaz).
- `docs/`: página del juego y política de privacidad (GitHub Pages: Settings › Pages › main › /docs).
